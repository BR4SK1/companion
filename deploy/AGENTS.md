# Deployment boundaries

- Target application containers to K3s, with non-production and production targets explicit and isolated. Keep their databases, credentials/secrets, storage, and external side-effect boundaries separate — with one narrow, owner-authorized exception: the OpenRouter provider API key may hold the same value in both environments, still delivered only through each environment's own Secret. That key's spend limits, revocation, and exposure are thereby shared between the environments (an event affecting the key in one environment affects both), and the owner has explicitly accepted this, including the risk that the key in use has been exposed previously. Every other credential, and the databases, storage, and side-effect boundaries, remain per-environment. PostgreSQL and Keycloak are existing external services; do not provision them here.
- Before enabling a release flow, identify the non-production candidate and ensure tests apply to that exact candidate. Production approval is the owner's merge; intended promotion uses the same tested immutable artifacts, without rebuilding or silently substituting them.
- Protect secret delivery and keep secret values out of source, public documentation, logs, and generated artifacts. Ignore rules are not a security boundary.
- Plan application-level migration compatibility and restart/order/idempotency verification before production use. PostgreSQL is an external application dependency this project does not operate: the database service's backup, recovery, and hardening are that service's own operating concern, not work this repository performs or gates on. Do not assume database rollback is safe, transactional, or guaranteed.
- The deployment trigger/controller is unresolved and not running. Do not claim that a merge deploys, that a release occurred, or that production was approved without verification. No production access or provisioning is implied.
- Follow the root `AGENTS.md` for repository-wide scope, public-content, and delegation rules. Documented future designs do not by themselves authorize implementation.
