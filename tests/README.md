# Test areas

Test coverage is organized by boundary: [`unit`](unit/README.md) tests run on Node's built-in test runner via `pnpm test:unit` and cover the OpenRouter Decisions and Chat contracts, the shared transport, the worker's pure turn logic and private HTTP API contract, and the web app's pure presentation, state, and BFF server-side logic; [`integration`](integration/README.md) validates component and service interactions — during ship-it its database-backed worker suites destructively use the positively verified non-production application database under exclusive maintenance and complete schema/configuration reconstruction; outside that workflow, they require a separately verified disposable isolated database or remain skipped; [`e2e`](e2e/README.md) exercises user-visible flows with Playwright against a run-owned disposable local stack (throwaway PostgreSQL, local fake provider, the web production build with its loopback test gate) with run-owned cleanup. The e2e suite is implemented; see its README for boundaries and coverage.

Vitest and Playwright are preferences for the integration and e2e stack, not installed or finalized dependencies. Unit tests use Node's built-in `node:test` runner with no added dependency; revisiting that choice belongs to any future test-stack decision. Future tests must use non-production data and isolated side effects, never production access.
