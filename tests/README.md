# Test areas

Test coverage is organized by boundary: [`unit`](unit/README.md) tests run on Node's built-in test runner via `pnpm test:unit` and cover the OpenRouter Decisions and Chat contracts, the shared transport, the worker's pure turn logic and private HTTP API contract, and the web app's pure presentation, state, and BFF server-side logic; [`integration`](integration/README.md) validates component and service interactions — destructive database-backed suites are explicit tools restricted to verified disposable databases and are not application-database shipping gates; [`e2e`](e2e/README.md) exercises user-visible flows with Playwright against a run-owned disposable local stack (throwaway PostgreSQL, fake OpenRouter chat/decision provider, real configured embedding service, and the web production build with its loopback test gate) with run-owned cleanup. Deployed non-production checks separately use the exact candidate and its unchanged provisioned configuration. See the area READMEs for boundaries and coverage.

Unit and integration tests use Node's built-in `node:test` runner; Vitest remains unselected. Playwright is installed for the disposable-stack and deployed-smoke harnesses. Future tests must use non-production data and isolated side effects, never production access or application-database resets.
