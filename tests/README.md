# Test areas

Test coverage is organized by boundary: [`unit`](unit/README.md) tests run on Node's built-in test runner via `pnpm test:unit` and cover the OpenRouter Decisions and Chat contracts, the shared transport, the worker's pure turn logic, the web preview's pure presentation logic, and the harness placeholder; [`integration`](integration/README.md) validates component and service interactions — the worker's database-backed durable-work suite runs there against an explicitly provided isolated non-production database and is skipped without one; [`e2e`](e2e/README.md) exercises user-visible flows with Playwright. The e2e folder documents intended ownership only.

Vitest and Playwright are preferences for the integration and e2e stack, not installed or finalized dependencies. Unit tests use Node's built-in `node:test` runner with no added dependency; revisiting that choice belongs to any future test-stack decision. Future tests must use non-production data and isolated side effects, never production access.
